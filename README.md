# reynard-soft7

`index.html` is the phone-first Soft7 landing. Share, in the header links, copies `https://tigerwillca.github.io/` or opens that link on X, and uses the device share sheet when the browser offers one. Link previews use the pinned phoenix banner.

`DEVELOPERS.md` is how that page is put together: the forest loop and the pause control, where the Share menu is allowed to sit, and the card viewer. Fee and address lines in that file are the copy in `index.html`. This branch does not contain the contract.
