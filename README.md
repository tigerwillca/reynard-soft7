# reynard-soft7

`index.html` is the phone-first Soft7 landing. Share, in the header links, copies `https://tigerwillca.github.io/` or opens that link on X, and uses the device share sheet when the browser offers one. The open menu is a single row placed off the seven cards. Link previews use the pinned phoenix banner.

`DEVELOPERS.md` is the Share placement, the copy and native-share results, and the forest loop.
